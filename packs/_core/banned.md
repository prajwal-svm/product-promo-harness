# Banned defaults (core)

Each item has an id. A pack re-allows an item only through `structure.json` → `allow`, with a
reason. The critic hunts for every item that the pack has not re-allowed.

| id | Banned |
| :--- | :--- |
| centred-title-on-gradient | A centred title on a gradient background |
| everything-fades-in | Every element entering with the same opacity fade |
| corner-labels | Labels or text parked in the frame corners |
| frame-borders | Decorative borders around the frame |
| ui-glow | Glow on UI chrome |
| particle-burst | Generic particle bursts |
| shockwave-ring | Expanding shockwave rings |
| rgb-split | RGB split / chromatic glitch |
| unmotivated-shake | Camera shake without an impact |
| lens-flare | Lens flares |
| neon-glow | Neon glows |
| grid-floor | Perspective grid floors |
| bouncy-type | Bouncy or overshooting easing on type |
| idle-sine-loop | Idle sine loops (breathe, float, drift, pulse) as sustained motion |
| black-to-accent-fade | Fading black directly into the accent colour (move an accent element between states instead) |
| dead-beat | A stretch with nothing happening |
| css-outline | CSS outlines or focus rings |
